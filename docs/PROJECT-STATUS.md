## 产品定位

> Paperin 是面向个人技术写作者和独立开发者的本地 Markdown 项目知识工作台，帮助用户把散落的项目资料写成带来源、可持续维护、可直接交付的文档。

短表达：**把项目资料，写成能交付、能继续维护的文档。**

当前核心任务：

```text
打开自己的资料
  -> 找到相关内容和来源
  -> 写成当前结论
  -> 安全保存并继续维护
  -> 交付 Markdown / HTML / PDF / Word 等成果
```
