# 导出支持范围

导出写的是新文件。取消、阻止或失败都不会改当前笔记。保存对话框选定路径后，写出前会再核对目标的真实身份；路径被换成链接或指向别处时拒绝写入，不会覆盖用户没选中的文件。资源包导出只写刚刚选定的目录，不会把当前知识库当成导出目标。

| 格式 | 预检 | 说明 |
| --- | --- | --- |
| Markdown | 有 | 另存为新的 `.md`。空图片和不安全链接会停；缺本地文件要确认；未完成任务只提醒。 |
| HTML / PDF | 有 | 先做同一套检查，再抓已经渲染的正文。自定义 CSS 写入前会去掉 `</style>` / `<script>` 片段；导入的样式文件必须是普通文件，符号链接不会被读进来。公式和图表依赖编辑器里已经画出的结果。 |
| Word | 有 | 同一套检查之后生成 `.docx`。图表优先变成图片，做不到时用占位文本，并在提示里说明。 |
| Pandoc（EPUB / LaTeX 等） | 有 | 同样先检查正文。没安装 Pandoc 时只提示安装，不会假装已经导出。 |

不支持的部分不会被悄悄删掉：未完成任务留在正文里，只在成功提示后提醒。大图片数据和不安全地址会在写出之前停下。代码块上的格式化按钮和折叠标记只在编辑器里显示；导出抓取正文时会去掉它们，被折叠挡住的代码仍写进结果。按标签或目录做集合导出时，已经打开的笔记用编辑器里的实时正文，未打开的笔记才读磁盘。导出内联本地图片时按文件句柄读取；路径被换成链接后不会把链接目标写进导出文件。

## 发布（HTML 资源包 / 富文本）

| 范围 | 资源包 | 富文本复制 |
| --- | --- | --- |
| 当前文档 | 支持（内联或 assets/） | 支持，按钮明确为「复制当前文档富文本」 |
| 当前目录 / 按标签 | 仅支持资源包（多篇合并为单个 HTML） | 不可用；不会静默改为只复制当前文档 |

- **按标签**：标签名为空时不能导出，也不会回退为「当前文档」。
- **集合上限**：单次最多 200 篇；超出会阻止并提示缩小范围。
- **索引完整性**：工作区索引未完整（`complete=false` 或 `truncated=true`）时拒绝集合导出，并说明索引不完整；任一篇读失败也不生成「部分成功」的资源包。
- **本地图片**：内联或 assets 模式下，任一 `mdimg://` 无法读取则取消导出/复制，不显示成功提示，不写入选定目录；当前 `.md` 原文不会被改写。
- **取消选目录**：用户在选输出位置时取消，不产生任何写入。

## 集合导出 Markdown → HTML（与单篇 DOM 导出区分）

标签/目录集合在写出 HTML/PDF/Word 前，会先把每篇 Markdown 经 `collection-markdown-renderer` 转成 HTML，再拼成合集。该路径**不会改写磁盘上的 `.md` 源文件**。

| 能力 | 集合 HTML 路径 | 说明 |
| --- | --- | --- |
| YAML frontmatter | 剥离 | 闭合的 `---` 块不进入正文；未闭合的 `---` 仍按普通 Markdown 解析 |
| GFM 脚注 | 保留 | 中文标签；引用与定义通过锚点关联 |
| 引用式链接/图片 | 保留 | 解析 `[label]` 定义；重复标签以最后一次定义为准 |
| 嵌套列表与列表内块 | 保留 | 子列表、段落、代码块、引用块按块级结构输出 |
| 行内/块级公式 | 源码 + 标注 | `data-export-degraded="formula"`，不内嵌 KaTeX |
| Mermaid  fenced 代码 | 源码 + 标注 | `data-export-degraded="mermaid"`，不执行图表脚本 |
| 来源侧 HTML | 转义 | 不透传 `<script>` 等；`javascript:` / `data:` 等 URL 降级为 `#` |

单篇「当前文档」导出仍抓取编辑器已渲染 DOM（公式/Mermaid 以编辑器画出的结果为准）。修复集合保真不等于 PDF/DOCX 全部格式已验收；Word/Pandoc 仍按各自管线单独验证。
