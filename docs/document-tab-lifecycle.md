# 文档标签生命周期边界

`useDocumentTabs` 是 `useDocumentSession` 的稳定门面；调用方仍通过同一套 API
创建、读取、切换、关闭、固定和重排标签，不直接依赖内部模块。

实现按副作用边界拆分：

- `useDocumentTabOpening`：新建、样例文件、系统打开对话框和工作区文件读取；它保留
  慢磁盘请求去重与“较晚读取不抢焦点”的选择意图规则。
- `useDocumentTabClosing`：预览回收、关闭前保存、草稿与自动保存清理、窗口关闭保存、
  固定和重排。
- `useWorkspaceDocumentView`：只持久化和恢复工作区内文件的选区/滚动状态；未命名和
  工作区外文件不写入工作区文档状态。
- `tab-close-plan`：关闭后的剩余标签和活动文档选择是纯函数，并由单元测试固定。

跨模块协调仍集中在入口：切换标签先落账旧编辑器内容、失焦标题、同步活动 ref，
再替换编辑器内容并恢复目标视图。这样 ProseMirror/Milkdown 仍是正文唯一状态源，
不会因拆分产生第二份可编辑正文状态。
