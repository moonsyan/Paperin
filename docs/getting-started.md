# 欢迎使用 Paperin

打开资料 → 用来源写一段技术说明

本地 Markdown 知识工作台：收下资料，写出理解，带来源交付

这份说明按功能模块介绍当前已经能用的能力。示例树里的笔记只存在于本机演示，**不会**写入你稍后打开的知识库文件夹。快捷键可以在「偏好设置…」里改；下面写的是默认键。macOS 上 Ctrl 对应 Command。

## 先试一个小任务

1. 在左侧打开 **资料来源** 里的两篇合成资料，或搜索 `R11_SYNTH_SOURCE_A_TTL`。
2. 打开 **API 网关技术说明（草稿）**（或命令面板新建「技术文章模板」），用 **插入引用** 写一段带依据的说明。
3. 保存后关闭再打开，确认正文与来源仍在。

## 打开资料

* **打开知识库文件夹**（Ctrl+Shift+O）：侧栏出现文件树、最近编辑和收藏。直接打开外部 Markdown 时，仍使用同一套标签、搜索、保存和编辑，不会把该文件自动收进知识库。
* **打开文件**（Ctrl+O）打开单篇。**新建文档**（Ctrl+N）得到未保存标签。
* **快速打开**（Ctrl+P）在已打开的标签和文件之间跳转。命令面板里输入 `>` 可以按名称运行命令。
* 命令面板可以新建六类普通 Markdown 模板：README、API 文档、设计文档、更新日志、技术文章、决策记录。模板不会覆盖已经打开的文件。
* 关闭全部标签后会出现开始页。有知识库时主按钮是「在此知识库新建」；没有知识库时主按钮是「打开知识库文件夹」。
* 从系统文件管理器打开 `.md` 时，单窗口设置下进入当前窗口标签，多窗口设置下打开独立窗口；不会被改写成知识库里的另一份副本。安装后的文件关联仍需平台验证。

## 写成文档

正文在编辑器里排版，磁盘上仍是普通 Markdown。

* 标题、列表、任务、表格、引用、代码、链接和图片都可以直接写，也可以用「更多… → 排版与插入」。
* 粗体 Ctrl+B，斜体 Ctrl+I，链接 Ctrl+K，图片 Ctrl+Alt+I，代码块 Ctrl+Alt+C。
* 公式用 `$...$` 或 `$$`。Mermaid 写成语言名为 mermaid 的围栏代码块；画不出来时可以切回源码。渲染前的清理不写回文件。
* 脚注用方括号加脱字符标出引用，定义单独写在行首并带冒号。
* JSON / YAML 代码块可以在块内格式化或压成一行。有缩进的代码可以折叠显示；折叠不改文件，复制和导出时去掉折叠按钮，代码仍在。
* 从其他软件粘贴 Markdown 原文时，按标题、列表和强调排版。剪贴板里的 HTML 只解析，不执行脚本。
* 侧栏「更多示例 / 快速开始.md」是 Markdown 语法速查，和这份入门分开。帮助菜单里也有「Markdown 语法」。
* **分栏预览**（Ctrl+Shift+P）并排看渲染结果。**专注模式**（F11）收起周围界面，Esc 退出。**打字机模式**让当前行保持在视区中部。

## 找来源并引用

* **全工作区搜索**在「更多… → 文档与知识库」里。普通关键词会把文件名和标题排在正文前面。最多列出 200 条命中；没扫完不等于没有结果。
* 搜索结果和侧栏「关系」里的反向链接都可以 **插入引用**。插入的是当时的文字片段和指向原文件的链接，不修改来源文件。从搜索插入后会回到打开搜索时的位置，可以用撤销收回。搜索期间换成另一篇文档再插入会被拒绝。
* 双方括号会按能解析的部分显示成链接。解析不了的原文保留。
* 再次打开同一知识库时，会填回上次搜索词，也能看到最近引用过的库内路径。这些记录可以清除，不会删除正文。
* 插入引用后会按**当前文章**记下来源的修改时间（不保存来源正文）。每篇文章有自己的来源基线；旧版全局快照会保留为「归属未知」，不会自动当作当前文章已复核。质量检查里会提示来源已变化、来源缺失，或索引还没完成；可用「复核当前文章」把基线更新为索引中的 mtime，**mtime 相同不等于已人工复核正文**。清除导航与删除来源关系是分开的动作。文件被移动或改名后，重新定位入口只打开搜索，不会自动改正文链接或完成关系迁移。

## 保存与继续维护

* **保存**（Ctrl+S）、**另存为**（Ctrl+Shift+S）。未保存的标签会标出 dirty；关闭标签或窗口前会确认。
* 外部程序改过同一文件时，保存会提示冲突，不会静默覆盖。编码可能丢字时会停下来让你选择，不会悄悄替换字符。
* 删除文件优先进系统回收站。
* **版本历史**可以查看并恢复先前保存过的内容。恢复进编辑器后仍需再保存，才会写回磁盘。
* 草稿、最近打开和界面布局与正文分开存放。工作区自己的界面状态写在库目录的 `.paperin` 里；删掉它不会删除笔记，但会丢失该库的布局、阅读位置、最近引用、来源记录和发布配置。应用数据目录另有草稿和索引缓存；保存中断后，正文旁可能保留含旧正文的恢复备份，不要随意清理。
* 图片默认保存在本地。只有你在设置里主动配置 SM.MS 之后，粘贴或拖入的图片才会上传。

## 检查质量

侧栏或上下文面板里的 **质量检查** 会提示断链、缺图、空标题、重复标题、脚注和未解析的 Wiki 链接。这些提示不改原文。

打开知识库后，如果索引还没扫完、附件缺失或链接对不上，只会给出说明。外部移动来源或增删图片后的提示仍有待完善的更新边界；交付前请核对实际来源和附件，不能把暂时没有提示当成全部已验证。

写作统计在「更多… → 帮助与说明 → 写作统计…」。它统计的是本机写作量，不是文件字数的唯一依据。

## 交付

「更多… → 导出与发布」：

* **导出 Markdown / HTML / PDF / Word**：写出前检查空图片、不安全链接和缺失的本地文件。未完成的任务列表只提醒，不会被删掉。
* **EPUB / LaTeX**：需要本机已安装 Pandoc。没安装时只提示，不会假装已经导出。
* **发布**：选择博客、技术文档、论文或公众号模板，范围可以是当前文档、当前目录或按标签。可保存最多 20 条配置，只记模板和范围，不含正文。
* **HTML 资源包**：包含 `index.html`、`assets/`，以及 `reports/paperin-delivery-report.json`。报告只有诊断计数和相对路径，不含正文、绝对路径或搜索词。
* **复制富文本**：只适用于当前文档，方便粘贴到其他编辑器。

取消选择导出位置时不会写入任何文件，也不会改当前 Markdown。集合导出在索引不完整时会拒绝，避免漏掉没扫到的笔记。

## 界面

* 顶栏左侧是 Logo、Paperin 和侧栏收起按钮。侧栏收起时 Logo 与名称一起隐藏。
* 侧栏有搜索、最近编辑、收藏和文件树。收藏按知识库记在本机，重启后还在。
* 右侧上下文面板默认可以收起。大纲、关系、标签、属性和质量检查从这里打开。**大纲面板**的默认快捷键是 Ctrl+Shift+L，**切换侧栏**是 Ctrl+J。
* 布局预设有写作、知识库、技术文档和出版四种，在「更多… → 视图与布局」里。
* 关系图谱从「知识图谱」打开。它是当前索引的一张图，不是另一套数据库。
* 帮助里有快捷键一览和 Markdown 语法。设置里可以改主题、字体、自动保存、拼写检查和自动更新。

## 数据放在哪里

正文始终是你文件夹里的 Markdown。应用不要求登录，也不会默认上传正文。

生产环境默认会检查更新、下载并在退出时安装；可以在设置里关闭，下次启动生效。开发环境不检查更新。拼写检查默认关闭；打开后可能会下载词典，不上传正文。

当前是 0.7.0 开发候选，安装循环、大型库性能和接收方格式验证尚未全部通过。Paperin 不做实时多人协作、账号、云同步或全库自动问答。和 Typora、Obsidian 可以先后打开同一篇文件；Paperin 保存时会检查外部修改，其他工具如何处理冲突取决于其自身实现。
