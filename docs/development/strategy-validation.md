# Paperin 战略验收协议与指标字典

> 版本：1.3｜2026-09-19。适用[战略定位](../PRODUCT-STRATEGY-ROADMAP.md)及[实施计划](../NEXT-DEVELOPMENT-PLAN.md)。
> 本文定义未来验收，不记录已达标结果。当前实测放在 [REFACTOR-STATUS](../REFACTOR-STATUS.md)。

## 1. 使用规则

所有数值是 Paperin 初始内部门槛，不是行业基准、竞品实测或对所有设备的 SLA。任务开始先冻结口径、夹具、阈值、设备和排除条件。调整必须记录原值、原因、批准角色和新版本；既有安全硬门禁不得为了变绿放宽，旧数据不能移到新口径下拼接。

每份结果至少记录：任务/指标 ID、commit、日期、OS、CPU、RAM、磁盘、Node/Electron、GPU/缩放、构建方式、夹具版本与特征、样本量、P50/P95/最大值、失败/取消/缺失、结果与限制。公开仅保留脱敏聚合；路径、正文、文件名、查询词和截图中的用户信息不得进入仓库。

工程目标与用户结果独立：代码测试通过说明已覆盖场景正确，不证明用户愿意持续使用；访谈说喜欢不证明数据安全；自愿样本不能外推全量人数。研究样本不足时写“未知/待验证”，不自动按未出现失败算成功。

当前执行映射（2026-09-19）：Q01 的可控注入点和二次授权拒绝已有自动回归，进程终止、真实磁盘/权限和平台矩阵未做。Q02 的保存身份、关闭复核和晚到回执已有自动回归，真实输入法和完整时序矩阵未做。M01 固定长段落 5 MiB Electron 硬门禁有通过记录，多结构、另一设备和 8 小时稳定性未做。S05–S11 的保存文案、搜索说明、来源插入、导航记录、打开检查、导出预检和两个模板已有工程实现；用户任务和平台打开检查未做。证据只维护在 [REFACTOR-STATUS](../REFACTOR-STATUS.md)。

## 2. Q01：文件写入、故障与恢复

主责 E/Q；对应 S01/S04/S14。使用隔离临时目录、合成中文/英文/emoji 和编码夹具，禁止对真实用户知识库做故障注入。

| 类别 | 必须覆盖 | 通过条件 |
| --- | --- | --- |
| 正常写入 | 新文件、已有文件、同路径连续保存、允许的符号链接 | 内容/编码/权限符合约定，mtime 回执对应已写版本；保留身份的场景满足平台文件对象要求 |
| 写入阶段故障 | 临时文件创建、写入、同步、目标提交、恢复材料写入/清理阶段（按选定设计） | 未确认操作不冒充成功；上一个确认版本仍在或能恢复，新内容尽可能保留在会话/恢复材料 |
| 运行中断 | 写入关键阶段中止进程、重启扫描恢复；恢复中再次中断 | 恢复幂等，不破坏正文，不删除唯一有效恢复副本 |
| 外部环境 | 磁盘满、权限拒绝、占用、外部修改/同尺寸修改、多窗口竞争 | 明确失败/冲突，禁止静默覆盖；每个恢复选择可取消 |
| 编码 | UTF-8/BOM、UTF-16、GBK 不可映射字符、不支持编码 | 不丢字符；ENCODING_LOSS/CONFLICT 保留显式用户决策 |
| 安全 | 路径逃逸、符号链接换靶、外部文件授权、超大小输入 | 复用 Main 安全边界，无信任路径旁路；失败不修改非目标文件 |

每个可控注入点至少 20 次重复；全部关键结果必须 100% 通过，不允许用总体 99% 掩盖一次数据破坏。存储提交设计决定哪些点可注入，未覆盖点写明。历史记录不天然替代写前恢复材料，需证明它在失败时已经可用。

“零丢失”只限约定故障矩阵和已确认版本，不保证硬件故障、操作系统故障、用户明确放弃的未保存输入都能恢复。进程终止测试不等于实机断电测试。保留文件对象、原子替换与持久性是不同属性，不能互相代替。

## 3. Q02：快照、版本、关闭与会话

主责 E/Q；对应 S02/S03。用编辑器状态、保存请求、磁盘正文校验和关闭结果联合断言，不能只看 DOM marker 或 toast。

| 维度 | 取值 |
| --- | --- |
| 大小 | 20 KiB、200 KiB、当前 UTF-16 code unit 阈值两侧、UTF-8 5 MiB |
| 内容形态 | 长段落、很多短节点、长行、中文/emoji、混合复杂语法 |
| 操作时序 | 输入后 0/50/200ms 保存/关闭/切标签；保存中继续输入；持续组合输入 |
| 快照状态 | 已落账、pending、超时 settled=false、编辑器未就绪、流式装载中 |
| 会话变化 | 等待中切文件/工作区、卸载、关闭重开、A/B 同名文件、多窗口同路径 |
| 文件结果 | 成功、冲突、编码取消、权限失败、删除、恢复失败 |

关键全组合：普通与 5 MiB × 输入后 0/50/200ms × 保存/关闭/切标签 × 已落账/pending/超时；每种至少 30 次。其余维度采用明确的成对组合并加入已知风险定向用例，报告覆盖表，不能写“所有组合已测”却只跑一条。

不变量：请求捕获文档/session 与目标编辑版本；快照与目标一致且足够新；回执只确认真实落盘版本。后续新输入未保存时 dirty 保留。pending 且缓存恰好等于旧基线时也不能判干净。超时/取消/未完成装载不能自动关闭；恢复/重试不将别篇快照写到当前路径。

草稿可恢复性另外验证：保存失败后重启能恢复最后已持久化草稿，显示其时间/版本限制；不能承诺尚未落账的输入自动可恢复。

## 4. Q03–Q06：交互、兼容、来源、隐私

### Q03：交互与可访问性

对应 S05。9 个内置主题都检查正常文本、必要控件边界、hover/disabled/focus、弹窗和系统标题栏；沿用 a11y 脚本门槛及用途例外，弱文字不能只因 token 名称而豁免。装饰分割线不与必要控件边界混同。

自动矩阵覆盖 1280×800、820px 断点两侧和 640×600 窄窗；100/125/150% 缩放；空库/示例/未命名/外部/同名文件/20 标签/dirty/保存中/错误。关键任务进行真实键盘、Escape、焦点恢复与中文 IME 手测。各承诺平台至少一种系统中文 IME；Windows 至少验证系统拼音。事件模拟只能补自动回归，不能代替真实 IME。

全部关键操作可达，无遮挡导致不可关闭/不可保存、无组合态误触发、无焦点丢失到不可操作区域，才通过。报告人工未执行项，不能以 token 门禁代替整套 UI 验收。

### Q04：兼容与试开

对应 S06。至少 5 类来源包：普通/Typora 风格 Markdown、Obsidian 导出或标准文件子集、Notion Markdown/CSV 导出、思源 Markdown 导出、语雀导出样例。各类至少 10 篇，尽量用当前来源工具实际导出的合成内容；拿不到官方导出样例时标“待验证”，手写模拟不能标真实兼容。

覆盖中文路径、同名目录、相对图片、编码、Wiki 链接/标题锚点、frontmatter、附件缺失、原生块/嵌入、未知语法、深度与文件预算截断。非编辑试开前后原 Markdown/附件 hash 100% 不变，应用元数据另计。转换只写副本，已支持内容/链接/附件完整，不支持内容保留原始材料并报告位置/原因；不静默删除字段或自动纠正正文。

Notion 数据库关系、Obsidian 插件、思源块身份和语雀协作信息不属于标准 Markdown 无损承诺。不能因对方可导出就假定 Paperin 无损兼容。

### Q05：来源插入与返回

对应 S08/S09。至少 24 条定向案例覆盖：同文档/跨文档、中文/同名标题、源文件变更/改名/删除、目标切换/关闭、键盘/鼠标、重复提交/撤销、工作区切换、重启恢复。

通过条件：引用文本与所选来源一致，来源链接可用或明确失效；目标身份稳定，不能插错文章；插入可单步撤销；返回原写作位置、选择和查询上下文，不覆盖正文、不创建重复标签。片段是插入时的快照，后续源文档变化不暗中重写当前文章。

### Q06：研究隐私与数据最小化

对应 S12。首轮允许纯人工日记，不要求产品新增事件系统；若做本地记录，只允许枚举事件、粗粒度日期、时长分桶、结果类型、指标版本等必要字段。Main 管理独立存储，设置与计数不混入正文。

禁止上传：正文、文件名、路径、搜索词、标题、选区、原文 hash、稳定文件身份或可关联文档的哈希。路径散列不是匿名。研究成员随机编号仅用于同意的队列随访，属于假名化，不宣传为完全匿名；与联系方式的对应表单独受控保存，不能进仓库。

上传默认关闭；本地统计可停用/清除；主动导出研究汇总须预览；撤回不影响应用核心功能。研究结束后建议原始日志最多保留 30 天并删除，脱敏汇总保留到该轮复盘后最多 180 天；实际研究开始前向参与者明确用途和时间。缺少同意不采集。外部网络请求需能区分更新等既有请求与研究上传，验收要求没有默认研究上传。

## 5. M01：性能预算与采样

对应 S03/S07/S10。固定一台参考机并记录完整配置，再选一台目标客群常见的 16GB RAM/SSD 设备复核；参考机未选定时目标仍是建议，不宣称跨设备达标。生产构建、无调试工具干扰；性能运行单独进行，不与 build/全量测试争抢资源。

| 场景 | 体验验收预算 | 起止点与夹具 |
| --- | --- | --- |
| 普通输入 | P95≤50ms | 输入/组合提交到下一帧正确文本可见；20/200 KiB，普通与复杂语法分报 |
| 普通保存 | P95≤500ms | 保存动作到目标版本写盘回执及正确 dirty 状态；不扣除快照等待 |
| 20 标签暖切换 | P95≤300ms | 操作到正确正文和位置可用，不仅是标签高亮；混合普通文档 |
| 5000 文件全文检索 | P95≤800ms | 输入动作到首批可见结果，含 debounce、IPC、UI；5000×2048B，另测混合大小库 |
| 操作取消反馈 | P95≤200ms | 取消动作到 UI 响应；后台取消传播/资源释放另作正确性检查 |
| 5 MiB 打开 | P95≤10s | 打开动作到正确全文可编辑，分五类节点形态，不只用长段落 |
| 5 MiB 保存 | P95≤5s | 提交到含目标编辑的磁盘确认，不能保存旧缓存达标 |
| 普通 HTML/PDF/DOCX 导出 | P95≤3s/5s/8s | 确定目标后到产物可读，含快照/资源处理；排除用户停留对话框时间，离线附件齐备的 200 KiB 样本 |

本轮沿用的既有 Electron 防卡死硬线：5 MiB 打开/保存各 120s、资源包导出 60s、20 标签 P95 10s。它们与体验预算分别报告：前者全过也不代表后者全过。其他现有回归阈值以脚本为准，禁止在本轮自动改基线。

普通场景至少 50 次样本、3 个独立运行批次；各批单独报告 P50/P95/最大值，三个批次都达标才通过。5 MiB 每种结构至少 20 次，批次至少 3 次运行分摊，报告每种结构分布；冷启动至少 10 次独立重启报告中位与最大值，不把 n=1 的冷索引称 P95。P95 使用排序后第 ceil(0.95×n) 项，超时保留为失败，不从时延统计偷偷排除；同时列出超时率。

首次建库冷索引与暖检索分开；缓存命中不能掩盖首次可用性。至少另测 5000 篇混合大小/复杂语法库以及超预算库，前者给出实际大小分布和实测，后者验收覆盖解释与不中断输入，不承诺超预算全部被搜到。

8 小时运行：输入/保存/搜索/切标签/文件监听组合，20 标签关闭重开循环至少 100 次；每 5 分钟采样 Main/Renderer 内存和监听数。首小时暖机后选稳定 30 分钟窗口，比较末 2 小时各 30 分钟窗口中位：增长≤15%且≤100MiB、无持续单调增长；监听/定时器达到预期基线。超标不能仅凭一次 GC 回落结案，应定位资源生命周期。

## 6. R01：搜索相关性

60 条人工标注任务：中文主题词 15、标题/路径/同名 10、英文与中英混合 10、段落定位 10、尾部文件/边界 5、无答案/未覆盖 10。标注哪些文件/段落能回答任务，不只把文件名含词作为正确。

其中 40 条开发集、20 条保留集；保留集冻结后不用于调排序，若泄漏需新建保留集。`Hit@5 = 有答案任务中前五结果含任一已标正确项的任务数 / 有答案任务数`；开发集、保留集分别≥90%，无答案项不计入该分母。另对无答案/未覆盖项要求 100% 正确说明状态，不能用随机结果填满提高表面命中。

已支持范围的精确词尾部命中 100%；每次改排序保留错误列表与中文分词/大小写/路径假设。搜索范围、深度、单文件大小、结果上限分别统计，不能把截断说成全库无内容。

## 7. A01/R02：任务效率与五分钟激活

### A01 激活

12 名符合画像的新用户，从首次看到产品起（安装完成；安装漏斗另算），无需口头帮助，在 5 分钟内完成：选择目录 → 打开笔记 → 编辑 → 磁盘保存成功 → 离开该笔记后通过目录/搜索再次找到。至少 10 人成功。超时、受助、错误保存计失败；可以记录完成耗时，但不能改成功定义。

试用队列的“激活用户”与 A01 一致，但队列激活允许发生在首次使用后的 7 天内，不要求五分钟；五分钟门槛单独报告。分母不能只挑做得快的人。

### R02 配对任务

12 人使用 Paperin 与自己的常用工具各完成 3 个等价任务：找到旧段落并插入来源；跨两篇资料写一段自己的结论并回到编辑点；形成可检查的交付文件。工具原配置保留，提供相同上手材料，记录学习/配置时间。

采用 A/B 顺序交叉，等价题组轮换避免记忆；每人限时每任务 15 分钟。成功必须内容与来源正确、目标文档正确、保存/成果可读，并能继续写作；不能用快速插入错误内容换速度。

人级成功：三项均独立完成；Paperin 至少 10/12 成功且失败人数不高于常用工具。对两工具均成功的用户，计算每人三任务总耗时的改善比例，中位改善≥30%；同时报告失败/受助/超时的完整样本，不只发表成功者速度。报告成功者数量和所有失败任务，样本不足不能宣布领先。

测试结束询问“下周会在哪个任务继续用”“是否愿保留原工具共存”，不使用诱导式“是不是更好”。保存 3 个主要阻塞和负面反馈的脱敏摘要。两轮小测试仍未改善则复核战略，不把继续加功能当默认答案。

## 8. E01：导出成果质量

12 篇合成文档中，7 篇分别重点覆盖公式、Mermaid、代码块、脚注、frontmatter、表格、任务列表，每篇同时含正常、中文、异常/不完整输入；另 5 篇覆盖长文分页、宽内容、相对图片/断链、混合语言字体和多来源文章。样本不含用户资料。

Markdown/HTML/PDF/DOCX × 12 篇 × 全部承诺平台建立输出矩阵。文本、结构、链接、图片用解析/哈希/语义断言；PDF/DOCX 逐页人工查看首尾、分页、表格/代码/公式/中文字体。Markdown 允许已声明的规范化，但不能语义丢失；无编辑试开仍必须字节不变。

通过要求：所有已声明支持项正文/来源/图片完整，无漏页、乱码、不可读截断；不支持项在导出前或结果中准确说明，不能用“不支持”临时豁免本来承诺的能力。DOCX 公式等采用明确子集/图片降级时预先登记。异常输入保留用户内容且安全，不执行脚本或未经授权访问路径。

5 MiB 另建大文档矩阵，至少含普通长文和混合结构；资源包 smoke 仅证明对应通道，不能替代真实 HTML/PDF/DOCX 菜单流程。PNG/截图不能替代可编辑 DOCX 或正文解析校验。

## 9. C01：留存、复用、成果与支持

### 9.1 行为定义

- 有效编辑：真实非示例文档发生用户有意义的修改并保存；仅切主题、自动格式化或打开不计。无法自动判断有意义时，用自愿日记确认并标为自报。
- 有效复用：从另一篇已有资料中取得片段/信息，插入来源链接或引用，并保存到当前成果；插入后撤销/删除不计。同一用户同一自然日重复同一成果只计一次；仅点搜索、打开反链或导出旧文件不计。
- 有用成果：用户完成可读交付文件或一篇已保存文章，并确认用于真实学习/工作任务；示例导出、按钮点击和失败导出不计。付费不是该指标前置。
- 研究北极星：某周至少完成一次有效复用的同意研究用户数，同时报告样本覆盖与来源。没有研究数据时为未知，不能以打开数替代。

纯本地自动事件只能提供代理信号；用日记/随访检验是否真实有用。自动与自报结果分列，不能混成一个看似精确的全量用户指标。

### 9.2 队列与分母

两批各至少 20 名已激活用户，按首次激活日记为 day 0；分别计算 day 7–13（W2）、day 21–27（W4）。队列窗口未满不纳入成熟结果，不把不同版本/来源随意合并。招募人数、安装人数、首次打开人数、激活人数分别报告，避免幸存者偏差。

| 指标 | 分子 / 分母 | 门槛 |
| --- | --- | --- |
| W2 有效留存 | W2 至少 2 个不同日有效编辑或复用的人 / 全部该批已激活用户 | ≥50%，预警指标 |
| W4 有效留存 | W4 至少 2 个不同日有效编辑或复用的人 / 全部该批已激活用户 | 两批分别≥40% |
| W4 复用留存 | W4 至少 1 次有效复用的人 / 全部该批已激活用户 | 两批分别≥25% |
| 首 14 天成果率 | day 0–13 至少一份有用成果的人 / 全部该批已激活用户 | 两批分别≥50% |
| 复用渗透率 | 当周有效复用者 / 当周有有效编辑或复用者 | 观察项，无独立通过门槛 |

失访保留在原分母并单列“未知”，不自动当作留存；展示保守值（已确认留存/n）及可能范围。明确撤回且不允许保留其数据的按同意协议删除，报告退出数量与分母变化，人数不足补招，不能利用删除失败者提高指标。多设备不暗中去重追踪，按同意的研究编号处理。

每批报告百分比和整数分子/分母、95% Wilson 区间；例如 8/20=40%，区间约 22%–61%，只能是早期信号，不能据此证明普遍市场需求。两批不能互相抵消，一批成功一批失败仍未通过。

### 9.3 支持与可靠性

操作成功率单列：成功保存/全部明确提交的保存请求；取消单列，冲突/权限/编码等已处理异常分类，不能全部移出分母美化。无产品统计时只报告测试或研究范围，不声称线上 99.9% 保存成功。

确认数据丢失、静默覆盖、错误关闭等每起都阻断相关发布，零次事故观察不等于任意环境零风险。反馈建议 2 个工作日内首答；数据安全反馈获知后立即进入最高优先级，不承诺无人值守的 24×7 SLA。

支持指标从≥100 名可观察 WAU 才作为扩张门槛：每周新增核心阻塞工单数/WAU×100≤5，连续 4 周；每周实际支持工时≤4 小时。核心阻塞包括不能安装/打开/保存/查找/输出等；重复同一用户同一问题合并计一个工单，多用户同类问题分别计数，不用归为一个 bug 隐藏影响。

## 10. B01：渠道与商业

渠道逐轮记录触达/到达（可得则报）、下载（仅意向）、安装、激活、成熟 W4 留存、运营时长、现金成本。只对同意归因的样本算渠道留存，未知来源独立列出。

`每名 W4 留存用户获客现金成本 = 本轮实际现金投入 / 已确认 W4 留存人数`；另给人力工时及按统一内部时薪折算的总成本。分母为零时成本为不可回收/无穷，不填 0。新队列未成熟不估已达标。先重复两轮，再加预算。

商业验证记录：合格试用人数、报价接触人数、真实付款人数、实收金额、30 天退款人数/金额、交付与支持时间、服务成本。愿付问卷、点击购买和意向登记分别列为代理，不计真实转化。实际收入门槛是非关联用户≥5、30 天观察完成、贡献毛利为正；没有成熟续费数据时不声称订阅续费/长期 LTV 已成立。

收费、预算支出、发布与主动联系都是后续执行事项，本次战略文档只定义决策条件，不触发这些外部行为。
