# Quiet Workspace 功能覆盖审查

## 结论

Demo 的主路径已经适合“打开知识库 → 选择文件 → 写作”，但还需要把生产能力映射到稳定的入口位置。当前最重要的优化不是增加按钮，而是让用户知道功能在哪里，并让后续功能有固定归属。

## 功能入口矩阵

| 能力 | 推荐入口 | 是否应出现在首屏 | 设计要求 |
| --- | --- | --- | --- |
| 打开知识库 | 工作区名称菜单 / 欢迎状态 | 是 | 默认动作，支持最近工作区 |
| 打开单个文件 | 文件树顶部“打开文件”或系统关联 | 否 | 打开后仍处于知识库工作台 |
| 新建文件 | 文件树标题旁加号、`Ctrl+N` | 是 | 新文件直接进入当前目录 |
| 搜索工作区 | 顶栏搜索、`Ctrl+K` | 是 | 支持文件名、正文、标签和命令 |
| 当前文档查找 | 编辑器内查找栏、`Ctrl+F` | 否 | 与工作区搜索状态完全分离 |
| 保存状态 | 当前标签、底部状态 | 是 | 显示已保存、保存中、冲突、编码提醒 |
| 大纲 | 正文右侧可折叠面板 | 否 | 不打开时不占正文宽度 |
| 反向链接/关联笔记 | 正文右侧面板 | 否 | 与大纲共用面板，不再开独立弹窗 |
| 标签 | 文件树次级视图 / 搜索筛选 | 否 | 不在默认文件树中混入第二套列表 |
| 图谱 | 命令面板、工作区视图菜单 | 否 | 作为工作区级视图，不作为编辑器按钮 |
| 版本历史 | 当前文件更多菜单 / 右侧面板 | 否 | 必须显示当前文件，不打断编辑上下文 |
| 导出 | 当前文件更多菜单 | 否 | Markdown、HTML、PDF、DOCX、Pandoc 分组 |
| 发布 | 当前文件更多菜单或工作区命令 | 否 | 只有配置可用时显示，避免空按钮 |
| 图片/附件 | 编辑器插入菜单、拖拽 | 否 | 保留当前文件目录和信任路径规则 |
| 主题/字体/快捷键 | 设置 | 否 | 不进入文档更多菜单 |
| 质量检查 | 工作区次级面板 | 否 | 显示问题数量，不抢占写作首屏 |

## Demo 需要补的四个状态

### 1. 无工作区状态

没有打开知识库时，正文区域不能直接展示示例文章。应提供三个明确动作：打开最近工作区、打开目录、直接打开 Markdown 文件。示例内容可以继续存在于设计 Demo，但正式空状态不能伪装成用户文件。

### 2. 外部文件状态

外部打开的文件需要在文件树上方显示临时的“当前文件”区域，包含路径来源和关闭动作。它不应该创建一个叫“单文件模式”的界面，也不能悄悄写入当前知识库索引。

### 3. 失去文件状态

文件被外部删除、移动或权限失效时，正文仍应保留当前内存内容，并显示“文件不可用”的状态。操作入口应包括重新定位、另存为和关闭，不允许直接清空编辑器。

### 4. 冲突和保存状态

当前 demo 的底部状态过于轻。正式版需要在标签和标题附近体现：保存中、已保存、外部修改、编码风险、草稿恢复。状态颜色只能作为辅助，必须有文字或可访问名称。

## 扩展布局建议

### 顶栏

固定为三个区域，避免功能继续堆叠：

```text
[侧栏] [工作区名称] | [标签……] | [搜索] [专注] [当前面板] [更多]
```

“当前面板”只负责打开右侧上下文面板，面板内部再切换大纲、链接、标签、历史和属性。

### 右侧上下文面板

建议将大纲、反向链接、标签、属性、历史和质量检查统一成一个可折叠面板。它们拥有相同的打开、关闭、宽度记忆和键盘行为，避免每个功能各自做一个弹窗。

### 工作区视图菜单

图谱、标签总览、质量检查和搜索结果属于工作区级内容，应使用工作区视图菜单或独立标签打开，不要塞入当前文档右侧面板。

## 兼容旧功能的注意事项

- 旧项目的 `workspace-state` 已经有侧栏视图、上下文面板、布局宽度和文档视图状态，新 UI 应直接映射这些字段。
- 旧项目的命令注册表已经负责快捷键和动作，新 UI 不应在组件里重新绑定同一快捷键。
- 文件搜索、标签索引、链接索引和文件监听都在主进程或专用 hook 中，界面只订阅结果。
- 版本历史、草稿恢复、保存队列和外部冲突不能被视觉重构隐藏或简化掉。
- 导出、图床和发布属于能力配置项，未配置时应隐藏或禁用并说明原因，不显示空按钮。

## 验收用例

每次 demo 或正式 UI 改版至少验证：

1. 从最近工作区打开并编辑文件，切换标签后内容不串。
2. 从系统直接打开不属于工作区的 Markdown 文件，仍能搜索、保存、另存为和关闭。
3. 文件被外部修改时，界面显示冲突并保留本地内容。
4. 文件被重命名或移动时，标签、面包屑、收藏、最近文件和草稿键同步更新。
5. 从命令面板执行导出、历史、图谱、主题和布局操作，顶栏不新增按钮。
6. 小窗口下侧栏和右侧面板使用同一抽屉逻辑，键盘可以打开和关闭并恢复焦点。
7. 没有工作区、索引加载中、索引失败、文件缺失和权限失败时都有明确空状态或错误状态。
