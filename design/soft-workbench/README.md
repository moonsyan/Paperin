# 柔和工作台原型

本次对应 [产品定位与重构规划](../../docs/SOFT-WORKBENCH-PLAN.md)。独立 React 原型，生产应用不变。现阶段免费、本地体验与 AI 资料复用优先；同步暂缓。

## 启动与验证

在仓库根目录执行：

```sh
npm run demo:soft
```

打开 [柔和工作台](http://127.0.0.1:5178/design/soft-workbench/index.html)。停止预览服务后，重新执行命令即可恢复。

```sh
npm run demo:soft:check
npm run demo:soft:build
npx vitest run design/soft-workbench/Workbench.test.tsx
```

构建输出在已忽略的 `out/soft-workbench/`，不提交生成代码。源码按壳层、导航、文档、面板、弹窗和窄窗焦点拆分，不导入生产 desktop API。图标复用 quiet-workspace 的 Phosphor sprite，许可见 [ICONS-LICENSE](../quiet-workspace/ICONS-LICENSE.txt)；品牌图标复用仓库资源。

## 建议体验顺序

1. 默认双栏：观察正文是否有明确重点，侧栏是否足够清楚。
2. 点击搜索，输入“散步”或“阅读”，打开结果；试试没有匹配的关键词。
3. 编辑演示正文，完成后切换标签再返回。修改仅本次保留，刷新恢复样本。
4. 点右上角辅助，依次查看大纲、关联、AI。关联项可以跳到另一篇笔记。
5. 点专注，再按 Escape 退出，原辅助面板恢复。
6. 从外观与说明切换雾白/夜松；缩窄窗口检查抽屉导航。

键盘：Ctrl/Cmd+P 搜索，搜索 Enter 打开首项，↓ 进入结果，Tab 浏览；标签 ←/→、Home/End 切换；Escape 关闭弹窗/抽屉或退出专注。输入法组合态不会触发 Escape/搜索提交。

## 真实边界

- 五篇合成笔记用于演示，编辑、新建和收藏只保留在页面内存。
- 文本只经过 React 转义与受限段落排版；不能替代 Milkdown 或代表其完整语法支持。
- 没有真实保存、标签关闭确认、AI 调用、云同步和在线发布。
- 原型布局状态没有写入生产 settings store，不会修改知识库或桌面设置。
- 两主题仅用于原型，正式迁移仍需验证九主题与系统标题栏。
